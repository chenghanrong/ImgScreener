## 使用方法
1. 双击 `main.exe` 运行
2. 点击「打开文件夹」加载图片。
3. 按 **`回车`** 暂停/继续播放，自动轮播显示文件夹内图片（速度可调）。
4. 按 **空格键** 一键保存图片到 `自定义` 目录,并暂停。
5. 支持键盘操控：**`←/→` 浏览，`↑/↓` 调速**。
